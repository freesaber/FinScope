v0.4.0：目标价与价格监控。

- 右上角新增目标价设置，在表格中为自选股填写买入价、卖出价并逐只勾选监控。
- 新增独立监控开关，开启后立即查询报价，随后每 60 秒更新；仅刷新价格，不重复获取财报。
- 当前价不高于买入价时显示蓝色「买」动画，不低于卖出价时显示紫色「卖」动画，离开条件后自动恢复。
- 目标价保存到本地，软件重启后监控默认关闭；移除公司同步清理对应监控配置。
- 主进程轮询最多并行查询 3 只股票，支持行情接口兜底与失败重试；关闭监控后丢弃在途响应。
- 保留现有财务筛选、卡片布局与东方财富跳转功能。
