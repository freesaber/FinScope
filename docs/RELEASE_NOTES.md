v0.4.2：交易时段与休市监控优化。

- 非交易时间开启监控或恢复启动时，仅更新一次报价，随后暂停轮询。
- 按北京时间 9:30–11:30、13:00–15:00 自动轮询；午休、收盘后、周末和交易所节假日暂停，下一交易时段自动恢复。
- 内置已确认的年度休市安排，并从上交所更新日历；未知年度尚未确认时暂停自动轮询，手动查询仍可使用。
- 软件启动恢复上次监控开关和目标价；休市时显示暂停原因及下次恢复时间。
- 系统休眠恢复后重新判断交易状态，避免非交易时间重复查价。
- 改善目标价弹框背景滚动锁定，保持页面原位置。
