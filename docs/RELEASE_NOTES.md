v0.4.1：托盘监控、每日提醒与行情卡片优化。

- 最小化到系统托盘，任务栏不显示窗口，监控继续运行；点击托盘恢复，右键菜单可退出。
- 触价时右下角显示不抢焦点的小提示框，支持右上角关闭，15 秒后自动收起。
- 同一股票按北京时间每天最多提醒一次，买卖共用额度；记录保存在本地，重启不重复。
- 卡片第二行改为价格与今日涨跌幅，不再显示股票代码。
- 开启监控后每 60 秒更新全部自选股；仅勾选目标价监控的股票显示右下角标记和买卖动画。
- 修复目标价弹框滚动穿透，打开时锁定背景，关闭后恢复原位置。

下载 `FinScope-Setup-0.4.1-x64.exe` 后退出旧版，按向导安装新版，保留原有自选名单和目标价配置。
